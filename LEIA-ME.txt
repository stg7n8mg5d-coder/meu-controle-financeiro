MEU CONTROLE FINANCEIRO — PACOTE PWA

Este pacote contém o aplicativo e os arquivos necessários para instalação como PWA:
- index.html: aplicativo
- manifest.webmanifest: nome, ícone e modo de instalação
- service-worker.js: cache para funcionamento offline após a primeira visita
- icon-192.png e icon-512.png: ícones

IMPORTANTE
1. O pacote precisa ser publicado em um endereço HTTPS para que iPhone e Android possam instalar e usar o cache offline.
2. No iPhone: abrir o endereço no Safari > Compartilhar > Adicionar à Tela de Início.
3. No Android: abrir no Chrome > menu > Instalar app ou Adicionar à tela inicial.
4. Abrir o aplicativo uma vez com internet para carregar os arquivos antes de usar offline.
5. Os dados financeiros ficam no armazenamento local do navegador/aplicativo. Use Exportar backup dentro do app regularmente.
6. O reconhecimento de voz pode depender do suporte do navegador e da conexão. O lançamento digitado funciona offline.

Este é um aplicativo web instalável (PWA), não um pacote nativo IPA/APK assinado para distribuição pelas lojas.
